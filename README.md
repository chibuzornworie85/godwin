# Table Tennis Hobby Website

This project is a simple and responsive webpage that showcases my favourite hobby — Table Tennis (Ping Pong).

The website highlights what table tennis is, why I enjoy playing it, and the benefits it offers such as improving reflexes, focus, and coordination. It also includes a gallery of images to visually represent the sport.

## Features
- Introduction to table tennis
- Reasons why I love the sport
- Image gallery showcasing table tennis
- Clean and simple layout

## Technologies Used
- HTML
- CSS

## Purpose
This project was created to practice basic web development skills and learn how to structure and publish a webpage using GitHub.
